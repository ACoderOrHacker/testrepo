# Issue Reports

`OE` uses [GitHub Issues](https://github.com/ACoderOrHacker/OE/issues) to get issues or bugs.

You can help us by [submitting an issue on GitHub](https://github.com/ACoderOrHacker/OE/issues).

!!! warning "Before you create an issue..."
    Make sure to search the issue archive -- your issue may have already been addressed!

## Bug Reports Requirements

Please try to create bug reports that are:

* *Reproducible.*: Include steps to reproduce the problem.
* *Specific.*: Include as much detail as possible: which version, what environment, etc.
* *Unique.*: Do not duplicate existing opened issues.
* *Scoped to a Single Bug.*: One bug per report.
* *Friendly*: Be friendly and respectful.
* *Grammatically Correct*: Use grammatically correct, complete sentences.

**Even better: Submit a pull request with a fix or new feature!**

## Steps

If you have found a bug or have an idea for a new feature and want to contribute, just follow these steps:

1. Take a look at [GitHub Discussions](https://github.com/ACoderOrHacker/OE/discussions) to see if it's already being discussed.
2. Create an issue with an available template.
3. Fill contents in templates.
4. Wait and communicate with contributors or users which have the same problems or ideas.

!!! note "Keep the messages clear"
    You should give clear and detailed messages to describe the issues.
    So that maintainers or contributors can know your ideas.

!!! note "Follow our Code of Conducts"
    You should follow our [Code of Conducts](code_of_conduct.md) when contributing codes.
