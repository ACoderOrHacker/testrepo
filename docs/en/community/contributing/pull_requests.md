# Pull Requests

`OE` uses [GitHub Pull Requests](https://github.com/ACoderOrHacker/OE/pulls) to receive high quality codes.

If you are interested in contributing, then take a pull request!

PRs are welcome!

## Pull Request Requirements

* *Unique.*: Do not duplicate PRs.
* *Scoped to a Single Bug Or Feature.*: One bug or feature per PR.
* *Friendly*: Be friendly and respectful.
* *Commit Messages*: Follow our [Commit Guidelines](../guidelines/commit_guidelines.md).
* *Grammatically Correct*: Use grammatically correct, complete sentences.

## Steps

If you want to contribute, follow these steps:

1. Search our repository for open or closed
   [Pull Requests](https://github.com/ACoderOrHacker/OE/pulls)
   that relate to your submission. You don't want to duplicate effort.
2. [**Take an issue**](issue_reports.md).
3. Fork this repository and write codes, make sure you follow the guidelines and the [Commit Guidelines](../guidelines/commit_guidelines.md).
4. Create a pull request.
5. Wait and communicate with contributors to merge the codes.

!!! note "Follow the Guidelines"
    You should follow the [Coding Guidelines in C++](../guidelines/code_guidelines_cpp.md)
    or [Coding Guidelines in D](../guidelines/code_guidelines_d.md).

    Follow our [Commit Guidelines](../guidelines/commit_guidelines.md) on committing.

!!! note "Follow our Code of Conducts"

    You should follow our [Code of Conducts](code_of_conduct.md) when contributing codes.
